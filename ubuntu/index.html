Ubuntuのセットアップ

WSL & Ubuntuの節に戻る

1. Ubuntuのインストール

WSLのインストール

WindowsのPowerShellで、次のコマンドを実行する。

wsl --install

Ubuntuのインストール

次のコマンドでUbuntuをインストールする。

wsl --install -d ubuntu

2. Docker DesktopとUbuntuの連携

  1. Docker Desktopの設定（Settings）を開く。
  2. Resources → WSL Integration に進む。
  3. WSL Integrationの項目をすべてONにする（UbuntuもONにする）。

Docker連携の動作確認

Ubuntuのターミナルで、次のコマンドを実行する。

docker run hello-world

Hello from Docker! と表示されれば、Docker連携は成功。

Docker DesktopのContainers画面にも、新しいコンテナが作成されていることを確認する。hello-worldのコンテナはメッセージを表示すると終了するため、停止済みの状態で表示されていれば正常。
