1. よく使うコマンド一覧

コマンド・使用例用途
pwd現在いるディレクトリの絶対パスを表示する。
ls / ls -laファイル一覧を表示する。-laで隠しファイルを含めて詳細表示する。
cd /path/to/dir指定したディレクトリへ移動する。cd ..で親へ、cd ~でホームへ移動する。
mkdir -p work/projectディレクトリを作成する。-pで途中のディレクトリも作成する。
touch memo.txt空のファイルを作成する。既存ファイルの場合は更新日時を変更する。
cp memo.txt memo-copy.txtファイルをコピーする。ディレクトリはcp -r source_dir copy_dirでコピーする。
mv memo.txt notes.txtファイルやディレクトリを移動する、または名前を変更する。
rm -i memo.txt確認してからファイルを削除する。ディレクトリごとの削除はrm -ri dir。通常はゴミ箱に入らないため、対象を確認する。
cat memo.txtファイルの内容を表示する。
less memo.txt長いファイルをスクロールして読む。qで終了する。
head -n 20 memo.txt / tail -n 20 memo.txt先頭・末尾の20行を表示する。tail -f app.logでログの追記を監視する。
grep -n "error" app.log文字列を含む行を行番号付きで検索する。
find . -name "*.txt"現在のディレクトリ以下から、名前に一致するファイルやディレクトリを探す。
nano memo.txtテキストを編集する。Ctrl + O、Enterで保存し、Ctrl + Xで終了する。
sudo apt updateインストール可能なパッケージの一覧を更新する。
sudo apt install gitパッケージをインストールする。sudoは管理者権限で実行する指定。
chmod +x script.shスクリプトに実行権限を付ける。./script.shで実行する。
ps aux / top実行中のプロセスを確認する。topは随時更新され、qで終了する。
df -h / du -sh .ファイルシステムの空き容量、現在のディレクトリの使用容量を確認する。
man lsコマンドの説明を読む。qで終了する。

入力途中でTabを押すとコマンドやパスを補完できる。実行中のコマンドを中断するときはCtrl + Cを使う。

2. Windows・Linux間のパスの対応関係

WSLの標準設定では、WindowsのドライブはUbuntuの/mnt以下から参照できる。逆に、Ubuntu内のファイルはWindowsのエクスプローラーから\\wsl.localhost\Ubuntu\で参照できる。

対象Windows側のパスUbuntu側のパス
CドライブC:\/mnt/c/
Dドライブ（ある場合）D:\/mnt/d/
WindowsのユーザーフォルダC:\Users\Tommy/mnt/c/Users/Tommy
このリポジトリC:\Users\Tommy\programing\record_for_build/mnt/c/Users/Tommy/programing/record_for_build
Ubuntuのホーム（ユーザー名がtommyの場合）\\wsl.localhost\Ubuntu\home\tommy/home/tommy（~）
Ubuntuのルート\\wsl.localhost\Ubuntu\/

UbuntuはWSLのディストリビューション名。実際の名前はWindowsのPowerShellでwsl -l -vを実行して確認する。Linuxのユーザー名はWindowsのユーザー名と異なる場合があり、Ubuntuでwhoamiを実行すると確認できる。

  • Windowsの区切り文字は\、Linuxは/。
  • Linuxの~はLinuxユーザーのホームを表す。WindowsのC:\Users\Tommyとは別の場所。
  • Linux側のファイル名は大文字・小文字を区別する。Memo.txtとmemo.txtは別のファイル。
  • パスに空白がある場合は、cd "/mnt/c/Users/Tommy/My Documents"のように引用符で囲む。
  • .は現在のディレクトリ、..は親ディレクトリ。/で始まるパスは絶対パス、それ以外は通常、現在の場所からの相対パス。

UbuntuからWindowsのファイルへ移動する

cd /mnt/c/Users/Tommy/programing/record_for_build
pwd

Ubuntuの現在の場所をエクスプローラーで開く

explorer.exe .

WSLでパス表記を変換する

# Windows形式からLinux形式へ
wslpath -u 'C:\Users\Tommy\programing\record_for_build'

# Linux形式からWindows形式へ
wslpath -w /mnt/c/Users/Tommy/programing/record_for_build
