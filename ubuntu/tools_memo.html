Ubuntuに入れたいツールメモ

トップページのWSL & Ubuntuの節に戻る

Ubuntuで開発するために入れたいツールの候補。インストール済みかどうかとは別に、用途をメモしておく。

入れたいツール

  • Git：ソースコードの変更履歴を管理し、GitHubとの連携に使う。Ubuntu側にも入れておきたい。
  • GCC：C・C++のコンパイルに使う。C++では主にg++を使う。
  • Miniforge：Pythonなどの環境・パッケージ管理に使う。プロジェクトごとに環境を分けたい。
  • Docker CLI：Ubuntuのターミナルからコンテナやイメージを操作する。
  • Codex CLI：ターミナルで使う開発支援ツール。

Docker CLIは、Docker DesktopとのWSL連携で使えるようになっている場合がある。追加インストールの前にdocker --versionとdocker run hello-worldで確認する。

追加で入れたいおすすめツール

C・C++開発

  • build-essential：GCC・G++・makeなど、Ubuntuでのビルドに必要な基本ツールをまとめて導入するためのパッケージ。
  • GDB：プログラムを途中で止めたり変数を確認したりするデバッガー。
  • CMake：複数のソースファイルやライブラリを使うプロジェクトのビルド設定を管理する。

まずはGCCを含むbuild-essentialから揃え、デバッグにはGDB、プロジェクトが大きくなったらCMakeを試したい。参考：Ubuntu公式のGCC開発環境ガイド

ファイル検索・閲覧

  • fd：ファイル名から素早くファイルを探す。公式リポジトリ
  • bat：コードを構文の色分けや行番号付きで表示する。公式リポジトリ
